# TNPSC Nova AI — Product & Feature Roadmap

---

## Overview

This document outlines upcoming user-facing features, interface improvements, and functional enhancements planned for TNPSC Nova AI.

---

## 1. Practice & Learning Engine Features

- [ ] **Interactive Bookmark Hub**: Dedicated page to manage, review, and filter bookmarked questions across all topics.
- [ ] **Custom Quiz Generator**: Ability for students to create personalized practice sets selecting custom subjects, difficulty tiers, and question types.
- [ ] **Time-Attack Mode**: Timed practice speed runs with live leaderboards.

---

## 2. Analytics & Visualizations

- [ ] **Interactive Weakness Matrix**: Interactive heatmap with direct "Practice Weak Qs" action triggers.
- [ ] **Syllabus Coverage Tracker**: Visual percentage completion bar for TNPSC Group 1, Group 2, and Group 4 syllabus modules.
- [ ] **Performance Projection Index**: Estimated exam score predictor based on accuracy and speed analytics.

---

## 3. UX & Visual Polish

- [ ] **Dark Mode / Cyber Theme Switcher**: Toggleable high-contrast themes for night study sessions.
- [ ] **Interactive Answer Review Filters**: Ability to filter question review by "Only Wrong Answers", "Flagged Questions", or "Time Spent > 60s".
